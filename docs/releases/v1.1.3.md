# IMSim v1.1.3

- Update NumPy to 2.5.4, SQLAlchemy to 2.1.6, and Ruff to 0.17.3.
- Fix GitHub Actions setup on Ubuntu 26.04 by selecting Python by minor version.
  CI continues to test Python 3.14 and 3.15.

For Docker deployments, set `IMSIM_IMAGE=ghcr.io/schmidtcode/imsim:v1.1.3` to pin
this release. No database migration is required.
