# IMSim v1.1.1

This maintenance release updates Dash Bootstrap Templates to 3.0.1, SQLAlchemy to 2.1.4,
isort to 9.0.2, and Ruff to 0.17.0. The Docker image uses Python 3.14.8. The CI and release
workflows use setup-python v7, and container publishing uses build-push-action v7.

Validation covered all 115 tests on Windows and in the Linux Docker image, lint and formatting,
package and container builds, PostgreSQL persistence across an app restart, stale-write
protection, admin access controls, and desktop and mobile simulator checks.

## Known issues

Two UI issues also occur in v1.1.0: Dash logs a missing inventory-table-grid callback target
on initial load, and the planner grid appears blank at a mobile width of 390 pixels.
The simulator and charts continued to run during validation.

## Deployment

Existing PostgreSQL 18 deployments can pull the new image and recreate the app. Set
IMSIM_IMAGE to ghcr.io/schmidtcode/imsim:v1.1.1 to pin this release. See the
[deployment guide](https://github.com/SchmidtCode/IMSim/blob/main/docs/deployment.md).
