# IMSim v1.1.0

This release updates the Python lockfile, including Dash 4.4.1, Dash AG Grid 35.3.0, NumPy 2.5.3,
Pandas 3.0.6, Plotly 6.9.0, Psycopg 3.3.6, SQLAlchemy 2.1.1, and Gunicorn 26.2.0. It also updates
the development tools, GitHub Actions, and Python 3.14.7 container base image. Dependabot now checks
uv, Actions, Docker, and Compose each week.

The bundled Compose deployments now use PostgreSQL 18 and its new data volume path. Existing
PostgreSQL 17 deployments need a database backup and restore into a new PostgreSQL 18 volume
before switching Compose files. See the [deployment guide](https://github.com/SchmidtCode/IMSim/blob/main/docs/deployment.md#postgresql-18-upgrade).

The app's training features are unchanged.
